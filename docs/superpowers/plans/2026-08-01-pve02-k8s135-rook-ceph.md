# pve02: k8s 1.35 + Rook-Ceph Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild do cluster k8s do workspace `pve02` com Kubernetes v1.35.7, containerd 2.2.6, Rook-Ceph v1.20.3 (SCs `ceph-block` default + `ceph-fs`) e discos de SO de 60 GB, sem tocar no pve01 (workspace `default`, continua Longhorn).

**Architecture:** Nova var `storage_backend` (`"longhorn"` | `"ceph"`) seleciona por workspace o que o cloud-init instala/formata e qual conjunto de helm releases sobe. Código Longhorn permanece para o pve01. Terraform: root → módulo `proxmox` (template cloud-init) e root → módulo `k8s-addons` (helm).

**Tech Stack:** Terraform (provider bpg/proxmox, helm), kubeadm v1beta4, containerd 2.2.6, Rook v1.20.3 (charts `rook-ceph` + `rook-ceph-cluster`).

**Spec:** `docs/superpowers/specs/2026-08-01-pve02-k8s135-rook-ceph-design.md`

## Global Constraints

- Kubernetes: `1.35.7-1.1` (repo apt `v1.35`), `kubernetesVersion: v1.35.7`, kubeadm config `v1beta4`
- containerd: `containerd.io=2.2.6-1~ubuntu.24.04~noble`
- Rook charts: versão `v1.20.3`, repo `https://charts.rook.io/release`, ns `rook-ceph`
- SC names: `ceph-block` (RBD, default) e `ceph-fs` (CephFS); replicas via `var.storage_replicas`
- Disco de dados dos workers = `virtio1` → `/dev/vdb` na VM; com ceph fica RAW (sem mkfs/mount)
- pve01 intocado: nenhum resource do workspace `default` pode ser destruído por estas mudanças (validado via `terraform plan` no Task 4)
- Working tree já tem mudanças não commitadas de outra frente; commits deste plano incluem só os arquivos listados em cada task
- Workspace/vars pve02: `terraform workspace select pve02`, `-var-file=secret.auto-pve02.tfvars`

- [ ] **Step 1: adicionar releases Rook**

```hcl
# Rook-Ceph (storage_backend = "ceph"): operator + cluster. OSDs usam o disco
# de dados raw dos workers (/dev/vdb, virtio1). SCs: ceph-block (RBD, default)
# e ceph-fs (CephFS RWX). Object store (RGW) fora por YAGNI.
resource "helm_release" "rook_ceph" {
  count            = var.storage_backend == "ceph" ? 1 : 0
  name             = "rook-ceph"
  repository       = "https://charts.rook.io/release"
  chart            = "rook-ceph"
  version          = "v1.20.3"
  namespace        = "rook-ceph"
  create_namespace = true
  timeout          = 600
}

resource "helm_release" "rook_ceph_cluster" {
  count      = var.storage_backend == "ceph" ? 1 : 0
  name       = "rook-ceph-cluster"
  repository = "https://charts.rook.io/release"
  chart      = "rook-ceph-cluster"
  version    = "v1.20.3"
  namespace  = "rook-ceph"
  # OSDs so ficam prontos depois de mon quorum + prepare jobs; 20 min de folga.
  timeout    = 1200

  values = [
    yamlencode({
      operatorNamespace = "rook-ceph"
      toolbox           = { enabled = true }
      cephClusterSpec = {
        dashboard = { enabled = false }
        mon       = { count = 3, allowMultiplePerNode = false }
        storage = {
          useAllNodes   = true
          useAllDevices = false
          deviceFilter  = "^vdb$"
        }
      }
      cephBlockPools = [{
        name = "ceph-blockpool"
        spec = {
          failureDomain = "host"
          replicated    = { size = var.storage_replicas }
        }
        storageClass = {
          enabled              = true
          name                 = "ceph-block"
          isDefault            = true
          reclaimPolicy        = "Delete"
          allowVolumeExpansion = true
          parameters = {
            imageFormat                                        = "2"
            imageFeatures                                      = "layering"
            "csi.storage.k8s.io/fstype"                        = "ext4"
            "csi.storage.k8s.io/provisioner-secret-name"       = "rook-csi-rbd-provisioner"
            "csi.storage.k8s.io/provisioner-secret-namespace"  = "rook-ceph"
            "csi.storage.k8s.io/controller-expand-secret-name" = "rook-csi-rbd-provisioner"
            "csi.storage.k8s.io/controller-expand-secret-namespace" = "rook-ceph"
            "csi.storage.k8s.io/node-stage-secret-name"        = "rook-csi-rbd-node"
            "csi.storage.k8s.io/node-stage-secret-namespace"   = "rook-ceph"
          }
        }
      }]
      cephFileSystems = [{
        name = "ceph-filesystem"
        spec = {
          metadataPool = { replicated = { size = var.storage_replicas } }
          dataPools = [{
            name       = "data0"
            failureDomain = "host"
            replicated = { size = var.storage_replicas }
          }]
          metadataServer = {
            activeCount   = 1
            activeStandby = true
          }
        }
        storageClass = {
          enabled              = true
          name                 = "ceph-fs"
          isDefault            = false
          pool                 = "data0"
          reclaimPolicy        = "Delete"
          allowVolumeExpansion = true
          parameters = {
            "csi.storage.k8s.io/provisioner-secret-name"       = "rook-csi-cephfs-provisioner"
            "csi.storage.k8s.io/provisioner-secret-namespace"  = "rook-ceph"
            "csi.storage.k8s.io/controller-expand-secret-name" = "rook-csi-cephfs-provisioner"
            "csi.storage.k8s.io/controller-expand-secret-namespace" = "rook-ceph"
            "csi.storage.k8s.io/node-stage-secret-name"        = "rook-csi-cephfs-node"
            "csi.storage.k8s.io/node-stage-secret-namespace"   = "rook-ceph"
          }
        }
      }]
      cephObjectStores = []
    })
  ]

  depends_on = [helm_release.rook_ceph]
}
```
